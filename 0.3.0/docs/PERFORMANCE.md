# 性能标注说明

各函数文档中的“性能”段落用于横向比较，不代表严格基准测试结果。标注基于
实现路径和典型谱面规模做静态估算；实际耗时还会受 Python 版本、硬件、数据
分布、对象数量和是否命中缓存影响。

## 相对开销 0-10

| 分数 | 含义 |
| --- | --- |
| `0` | 常量级，几乎只做标量/颜色运算 |
| `1-2` | 单个对象、单个关键点或一次局部数组操作 |
| `3-4` | 线性扫描、批量局部插入，或返回一段数组的副本 |
| `5-6` | 全谱级遍历、规范化、校验或中等规模几何计算 |
| `7-8` | 全谱 `floorPosition` 重算、深复制、较大填充/边框计算 |
| `9-10` | 图结构、栅格骨架、高精度填充或大量文字/节点，最容易受大参数影响 |

分数是相对尺度：同一个 `n` 下，`8/10` 通常会明显比 `3/10` 更早成为瓶颈。

## 复杂度符号

- `V`：谱面中被遍历/重算的节点总量（线节点、Note、BPM、画布关键点等）。
- `n`：当前函数直接处理的数组长度或返回节点数。
- `m`：批量输入的元素数量。
- `p`：多边形顶点数或一条线的线节点数。
- `c`：判定环/线色/颜色节点数。
- `B` / `C`：BPM 节点数 / 画布或摄像机关键点数。
- `T`：Riztime、主题或时间线节点数。
- `L`：谱面线数。
- `K`：复制或插入操作直接产生的节点数。
- `F`：填充线或射线数量，通常约等于 `1 / precision`。
- `R`：文字栅格像素数；`I`：骨架细化迭代次数。
- `E`：闭合区域平面图的边/交点数。

## 使用建议

- 先看“相对开销”，再结合“时间复杂度”判断输入规模扩大时的增长趋势。
- 同一函数如果模式差异明显，会在“大参数提示”中单独说明，例如：
  - `isDelayCalculate=False` 与全谱 `refresh()`；
  - `isFailAddAllowed=False` 的深复制预演；
  - `precision` 变小导致填充线/采样点数量上升；
  - 文字长度、字号、`smoothness` 对栅格和骨架节点数的影响。
- 性能段落中的复杂度是数量级估计；常数项没有展开。对性能敏感的生产代码建议
  使用真实谱面做基准测试。
