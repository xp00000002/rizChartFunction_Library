# 国际化与语言配置

[← 返回文档入口](README.md)

本页说明 `rizChartFunction` 的语言管理、配置读取、语言包和 API。

## 默认语言

默认语言为英文：

```python
import rizChartFunction as rcf

rcf.get_language()
# "en"
```

可用语言：

```python
rcf.available_languages()
# ("en", "zh-CN")
```

## Python API

```python
from rizChartFunction import (
    available_languages,
    get_language,
    reload_language,
    set_language,
)
```

- `get_language()`：返回当前语言代码，复杂度 `O(1)`。
- `set_language(language)`：切换当前进程语言，返回规范化后的语言代码。
- `reload_language()`：重新读取配置文件和语言包。
- `available_languages()`：返回内置语言代码。

`set_language()` 和 `reload_language()` 没有异常路径，因此不接受
`isReturnException`。未知语言会发出警告并回退到英文。

```python
rcf.set_language("zh_CN")   # 规范化为 "zh-CN"
rcf.get_language()          # "zh-CN"

rcf.set_language("en")      # 回到英文
```

## 配置文件

配置文件为 JSON：

```json
{
  "language": "zh-CN",
  "isReturnException": true
}
```

`isReturnException` 是全局异常默认值，详见 [EXCEPTIONS.md](EXCEPTIONS.md)；
`language` 是当前显示语言。配置路径优先级从高到低：

1. `set_language()` 运行时设置
2. 环境变量 `RIZCHART_LANGUAGE`
3. 环境变量 `RIZCHART_CONFIG` 指定的 JSON 文件
4. 当前工作目录的 `.rizchartfunction.json`
5. 用户目录的 `~/.rizchartfunction/config.json`
6. 默认 `en`

环境变量示例：

```powershell
$env:RIZCHART_LANGUAGE = "zh-CN"
$env:RIZCHART_CONFIG = "E:\config\rizchart-lang.json"
```

修改配置文件后需要调用：

```python
rcf.reload_language()
```

或者重启 Python 进程。

## 语言文件

内置语言文件位于：

```text
src/rizChartFunction/locales/
  en.json
  zh-CN.json
```

结构：

```json
{
  "meta": {
    "language": "en",
    "name": "English",
    "version": 1
  },
  "messages": {},
  "docs": {}
}
```

- `messages`：异常消息键和模板。
- `docs`：公开函数文档字符串覆盖。
- 缺失消息键会先回退到英文，再回退到键名本身。
- 缺失文档条目会保留源码中的英文 docstring。
- 语言代码使用规范化形式：`en`、`zh-CN`。

## 已知限制

- 运行时修改 `__doc__` 对 `help()` / `inspect.getdoc()` 可见，但 IDE 的
  静态悬浮提示通常仍显示源码 docstring。
- Sphinx 等静态文档需要按语言分别构建。
- 修改配置文件后，运行中的进程不会自动感知，需要调用
  `reload_language()` 或重启。
