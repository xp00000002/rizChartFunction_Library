# Rizline 参数示意图工具

`chart-parameter-visualizer.html` 是一个独立的单文件网页，不属于 `rizChartFunction`
库的导出内容。直接用浏览器打开即可使用，不需要安装服务或联网。

```text
tools/chart-parameter-visualizer.html
```

（`tools/README.md` 所在目录中的 `chart-parameter-visualizer.html`。）

也可以双击文件，或在浏览器地址栏使用 `file:///` 打开。

## 三个页签

1. **缓动插点**
   - 输入起点、终点、缓动类型、插入策略和 `precision`。
   - 输出插入点坐标。
   - 支持两种显示内容：
     - **二维直线插点**：x/y 同时按缓动变化，适合看几何插点位置。
     - **线节点缓动（time/X）**：Y 使用线性时间，X 使用缓动，适合看谱面线节点的
       `xPosition` 过渡。橙色折线连接实际节点，淡橙虚线表示目标缓动曲线。
     - 也可以两者同时显示：蓝色圆点为二维插点，橙色方块为线节点。
   - 支持 `0..25` 缓动和 Cubic Bezier 自定义。
   - 插入策略包含 `uniform` / `arc` / `curvature` / `recursion` / `priority`。
   - `recursion` / `priority` 基于曲线误差插点；选择 Linear 时曲线是直线，不会
     产生插入点，请换用非线性缓动观察效果。

2. **填充线**
   - 输入多边形点列表、填充方式、中心点、角度和 `precision`。
   - 默认图形是 `0.4 × 0.3`，符合谱面常用的小坐标尺度。
   - 输出每条填充线的两个端点。
   - 支持 `linear` / `radial` / `conic` / `radialBorder` / `conicBorder`。
   - 非边界模式的 `precision` 是整圆比例，例如 `0.01 ≈ 3.6°`；
     边界模式是沿多边形边界的采样距离。

3. **细字骨架**
   - 输入字符串、锚点、字体、对齐、字号、字距和 `smoothness`。
   - “字体”输入框只能填写一个字体名称，不能使用逗号分隔的字体列表。
   - 可以选择本地 `TTF` / `OTF` / `WOFF` / `WOFF2` 字体文件，用浏览器
     `FontFace` 加载；文件只在本地浏览器内使用，不会上传。浏览器通常不能直接
     加载 `TTC`，需要先转换成单个 TTF/OTF。
   - 字号使用与坐标相同的模型单位，默认 `0.2`。
   - 在浏览器内栅格化文字、提取一像素骨架，再简化/平滑。
   - 字号很小时栅格像素会变少，骨架可能断裂；页面会自动提高光栅倍率，
     但仍建议不要使用过小的字号。
   - `Y 倍率` 固定为 `1.0`。
   - 可使用浏览器系统字体，也可加载本地字体文件；字形仍可能与实际谱面
     使用的字体版本有差异。

## 说明

- 画布使用数学坐标，Y 轴向上。
- 页面用 Canvas 绘制示意，不依赖本库运行。
- 输出区是可复制的 JSON；可将坐标粘贴到其他绘图或谱面工具中。
- 缓动页根据显示内容输出 `{ "direct": [...] }`、`{ "linePoint": [...] }`，
  或同时包含两者。
- 地址栏的 `#ease` / `#fill` / `#text` 可以直接打开对应页签。
